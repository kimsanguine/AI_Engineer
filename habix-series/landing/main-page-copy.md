# 하네스 엔지니어링 (Harness Engineering)

> habix.ai 한국어 시리즈 · 김생근 운영

---

## 1. Hero

# Claude Code가 일을 끝까지 못 끝낸다면, 모델이 아니라 하네스가 문제입니다.

모델은 충분히 똑똑합니다. 끝까지 가지 못하는 건 작업장(하네스)이 비어 있기 때문입니다. 12챕터로 비개발자도 자기 루틴을 에이전트에게 맡기는 법을 배웁니다.

[ 15분 읽기 + 5분 액션 ]   [ 30일 루틴 챌린지 시작 ]

운영자: 김생근 · 20년 PM · AI SaaS CPO · 100 Agents 직접 운영 중

---

## 2. 이 시리즈를 읽어야 할 사람

### PM 출신 빌더
**"기획은 되는데, 손이 모자랍니다."**
- 페인: 백로그는 끝없이 쌓이는데 코드를 끝까지 마감해 줄 사람이 없습니다.
- 이득: 의도를 한 장(feature_list)으로 적으면 에이전트가 마감까지 끌고 갑니다.

### 1인 SaaS 창업자
**"바이브 코딩으로 v1은 만들었는데, v2가 안 됩니다."**
- 페인: 매번 처음부터 설명하느라 어제 한 일을 오늘 또 잃어버립니다.
- 이득: 폴더가 기억하게 만들면 어제 끝낸 자리에서 오늘 이어갑니다.

### 마케터·디자이너 출신 빌더
**"코드는 모르지만, 제품은 끝내고 싶습니다."**
- 페인: 도구는 많이 봤지만, 매일 굴러가는 루틴으로 묶이지 않습니다.
- 이득: 5분 액션 12개로 "내가 안 봐도 도는 작업장"이 만들어집니다.

## 3. 시장의 빈자리

워킹랩스(walkinglabs)는 개발자에게 코드 수준으로 깊게 들어갑니다. 노마드코더·패스트캠퍼스는 "도구"를 가르칩니다.

habix.ai는 *루틴*을 가르칩니다. 도구 사용법이 아니라, 비개발자가 매일 30분으로 에이전트에게 일을 시키는 습관을 만듭니다.

> "바이브 코딩은 결과물을 만들고, 의도 기반 에이전트는 *지속*을 만듭니다."

## 4. 챕터 구성

### 0주차 — 프롤로그 (3편)
- **P-01. AI에게 일 시킨다는 것** — "쓰는 것"과 "시키는 것"의 차이부터 인정합니다.
- **P-02. 1주차에 외울 15개 단어** — 하네스 사전을 먼저 깔아둡니다.
- **P-03. 내 도구 스택 정하기** — Cursor냐 Claude Code냐, 30분이면 결정 끝.

### 본 강의 — 12챕터
- **01. 왜 똑똑한 AI도 내 앱은 끝내지 못하는가** — 모델 탓이 아닌 진짜 이유를 분해합니다.
- **02. 하네스란, AI에게 일 시키는 작업장 차리기** — 작업장 5요소를 처음부터 깝니다.
- **03. 채팅창 말고 폴더가 기억하게 하라** — 대화창은 휘발성, 폴더는 자산입니다.
- **04. CLAUDE.md 한 장으로 AI에게 우리 프로젝트 가르치기** — 단 한 장, 그러나 가장 중요한 한 장.
- **05. AI는 어제 한 일을 잊는다 — 메모를 남겨라** — progress.md로 어제와 오늘을 잇습니다.
- **06. 시작 전에 5분, AI에게 우리 프로젝트 브리핑** — 매 세션 첫 5분이 그날의 품질을 결정합니다.
- **07. AI가 일 키우는 걸 막는 법** — 스코프 폭주(scope creep)를 의도로 막습니다.
- **08. 할 일 한 장이 모든 것을 바꾼다 (feature_list)** — 의도를 데이터로 적는 순간 마감이 가능해집니다.
- **09. '됐어요'를 믿지 마라, 증거를 요구하라** — 완료 보고가 아니라 증거를 받습니다.
- **10. 실제 사용자처럼 클릭해보는 자동 테스트** — Playwright로 사용자의 손을 흉내냅니다.
- **11. AI가 뭘 했는지 들여다보는 창문 (관측 가능성)** — 로그·트레이스로 블랙박스를 엽니다.
- **12. 내일의 나를 위해 책상 정리하고 나가기** — 세션 종료 체크리스트로 내일을 미리 만듭니다.

### 캡스톤
- **C-01. 내 첫 30일 루틴 챌린지** — 12챕터를 30일 루틴으로 굳힙니다. 마지막 날, 작업장은 혼자서도 굴러갑니다.

### 보너스

- **13. 한 달 후, 내 루틴 파일을 리팩토링하는 법** — 한 달이 지나면 *추가*보다 *정리*가 중요해집니다. 매월 1일 30~60분, 책상이 아니라 *규칙 자체*를 정돈하는 의식.

---

## 5. 무엇이 다른가

- **1인칭 일지로 씁니다.** 강의가 아니라 운영자의 작업 기록입니다. 막힌 자리, 헛다리, 다시 푼 자리를 그대로 남깁니다.
- **before/after 스크린샷이 들어갑니다.** "이 한 줄을 CLAUDE.md에 넣기 전/후"의 차이를 화면 그대로 보여드립니다.
- **각 챕터 끝에 5분 액션이 있습니다.** 읽고 끝이 아니라, 그 자리에서 한 번 손이 움직이게 설계했습니다.
- **루틴팩(Routine Pack)을 그대로 가져갑니다.** 글로 끝나지 않습니다. 운영자가 쓰는 템플릿을 5종 묶음으로 내려받습니다.

## 6. 운영자 소개

**김생근** — 20년 프로덕트 매니저, AI SaaS CPO.

지금 100개의 AI Agent를 직접 만들고 실행 중입니다. 링크 모음이 아니라, 문제 정의부터 코드와 실행 결과까지 매일 한 개씩 쌓고 있습니다.

> **"Agent를 설명하지 말고, 실행해서 보여줘라."**

이 시리즈는 그 작업장에서 매일 쓰는 도구를 PM 1인칭으로 정리한 것입니다.

## 8. 자주 묻는 질문

**Q1. 코드를 한 줄도 모르는데 따라갈 수 있나요?**
네. 12챕터 전체가 "코드를 쓰는 법"이 아니라 "에이전트에게 일을 시키는 법"입니다. 챕터 3·4·8만 따라 해도 작업장이 섭니다.

**Q2. Cursor와 Lovable, Claude Code 다 필요한가요?**
아니요. 0주차 P-03에서 하나를 고르도록 안내합니다. 본 강의 예시는 Claude Code 기준이지만, 다른 도구로도 그대로 옮길 수 있게 적었습니다.

**Q3. 챕터당 소요 시간은 얼마인가요?**
읽기 15분 + 5분 액션 = 챕터당 20분이 기본입니다. 캡스톤(30일 챌린지)은 하루 30분을 30일 묶는 구조입니다.

**Q4. 30일 챌린지가 안 맞으면 환불되나요?**
유료 챌린지 참여 후 7일 이내, 1주차 액션을 마쳤다면 100% 환불해 드립니다. 시도 자체를 막지 않기 위함입니다.

**Q5. Claude Code 말고 다른 도구를 써도 되나요?**
됩니다. 본 시리즈는 "하네스"를 가르치는 것이지 특정 도구를 가르치는 것이 아닙니다. Cursor·Windsurf·Aider 사용자를 위한 대체 명령도 챕터 하단에 함께 적어둡니다.
