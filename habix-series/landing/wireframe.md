# 하네스 엔지니어링 랜딩 페이지 — 와이어프레임 (Wireframe)

> habix.ai 한국어 시리즈 메인 랜딩 · 9개 섹션 명세

## 브랜드 컬러 가정 (Brand Color Assumption)

- Primary (잉크 블랙): `#0A0A0B` — 본문 텍스트, Hero 배경
- Accent (하네스 옐로): `#FFE34D` — CTA 버튼, 강조 하이라이트
- Sub Accent (작업장 그린): `#1FBF75` — "지속(Continuity)" 강조, 챕터 04 배지
- Surface (페이퍼 화이트): `#FAFAF7` — 본문 배경
- Border (라인 그레이): `#E5E5E0` — 카드 보더, 구분선
- Muted (메모 그레이): `#6B6B66` — 부제, 캡션

레이아웃 기준: 1200px 컨테이너, 12-column grid, 모바일 break 768px.

## 섹션 01 — Hero

### 레이아웃 (Layout)

```
┌──────────────────────────────────────────────────────────────┐
│  [logo: habix.ai]                       [내비: 챕터 / 챌린지] │
├──────────────────────────────────────────────────────────────┤

│                                                              │

│  모델이 아니라 하네스가 문제입니다.                           │
│                                                              │
│  모델은 충분히 똑똑합니다. 끝까지 가지 못하는 건              │
│  작업장(하네스)이 비어 있기 때문입니다.                       │
│                                                              │
│  [ 15분만에 챕터 1 읽기 ]   [ 30일 루틴 챌린지 시작 ]         │
│                                                              │
│  ─ 운영자 김생근 · 20년 PM · AI SaaS CPO · 100 Agents ─       │
└──────────────────────────────────────────────────────────────┘
            │ (배경: 어두운 잉크 블랙 + 옐로 점선 격자)        │
```

### 권장 컴포넌트 (Components)

- Hero with full-bleed dark background (그리드 패턴 오버레이)
- Pill badge: "하네스 엔지니어링 · 12 Chapters"
- H1: 60–72px desktop, 36px mobile, 줄바꿈 강제 (2줄)
- Primary CTA (옐로 솔리드) + Secondary CTA (화이트 아웃라인)
- Operator strip: 한 줄 텍스트, muted 컬러

### 추천 시각 자료 (Visuals)

- Hero 우측 또는 배경 레이어: 터미널 캡처 모형 + CLAUDE.md, progress.md, feature_list.json 3개 파일 아이콘이 정렬된 미니 다이어그램.
- 배경: 점선 그리드 (작업장 = "정렬된 공간" 은유).

### 모바일 단순화 (Mobile)

- 우측 시각 자료 제거, H1만 단독 노출.
- CTA 2개를 세로 스택, primary가 위.
- Operator strip은 캡션 사이즈로 축소.

### 색상 활용

- 배경 Primary, 텍스트 Surface, CTA Accent(옐로) + Sub Accent(그린).
- Pill: 옐로 8% 투명 배경 + 옐로 텍스트.

## 섹션 05 — 무엇이 다른가 (Differentiation)

### 레이아웃

```
┌─ H2: 무엇이 다른가 ──────────────────────────────────────────┐
│                                                              │
│  [Diff 1]            [Diff 2]                                │
│  1인칭 일지          before/after 스크린샷                   │
│  ─────────           ─────────                               │
│  설명…               설명…                                   │
│                                                              │
│  [Diff 3]            [Diff 4]                                │
│  5분 액션            루틴팩 다운로드                         │
│  ─────────           ─────────                               │
│  설명…               설명…                                   │
└──────────────────────────────────────────────────────────────┘
```

### 권장 컴포넌트

- 2x2 feature grid
- 각 셀: 좌측 큰 번호(01–04, outline) + 헤드라인 + 본문
- Diff 2(before/after) 셀에 작은 듀얼 스크린샷 미리보기 슬롯

### 추천 시각 자료

- Diff 2: before/after 분할 스크린샷 (좌: 빈 폴더 / 우: CLAUDE.md, progress.md 들어찬 폴더).
- Diff 4: 루틴팩 5종 파일 아이콘 스택(zip 아이콘 형태).
- Diff 1, 3: 단순 라인 일러스트(노트북에 손글씨, 5분 타이머).

### 모바일 단순화

- 2x2 → 1-column 세로 스택.
- 큰 번호는 좌측 정렬 → 상단 정렬로 변경.

### 색상 활용

- 큰 번호(outline) Border 컬러, 헤드라인 Primary, 본문 Muted.
- before/after 보더만 Accent로 처리해 시선 유도.

## 공통 컴포넌트 노트 (Shared Components)

- `<Pill>` — 8% 투명 배경 + 동일 컬러 텍스트, 12px, 라운드 9999px
- `<PullQuote>` — 좌측 5px Accent 바 + serif 또는 굵은 sans 24px
- `<ChapterRow>` — 번호 배지 / 제목 / 후킹 / 시간 pill / 화살표 5분할
- `<CTAButton>` — Primary(옐로 솔리드, 검정 텍스트) / Secondary(투명 + 화이트 보더)
- `<Card>` — Surface 배경, Border 1px, padding 24px, radius 12px

## 접근성 & 성능 노트 (A11y / Perf)

- 모든 CTA는 키보드 포커스 링 표시(Accent 2px outline).
- Hero 이미지는 `loading="eager"`, 그 외 시각 자료 `loading="lazy"`.
- 다크 Hero / 라이트 본문 — 충분한 대비비(AA 이상) 확보.
- 아코디언은 `aria-expanded` 토글, 탭은 `role="tablist"` 사용.
