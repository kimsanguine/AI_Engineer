# session-end-checklist.md — 세션 종료 5분 체크리스트

## 왜 세션 종료가 중요한가
세션 종료는 다음 세션의 출발점입니다.
종료를 생략하면 다음 세션은 "어디서부터 시작해야 하지"부터 다시 시작합니다.
5분의 정리가 다음 30분의 헤맴을 막습니다.

## 이 체크리스트를 5번 무시하면 어떤 일이 일어나는가
첫째, 같은 버그를 두 번 세 번 다시 디버깅하게 됩니다.
둘째, 사람 결정 대기 항목이 쌓여서 진척이 멈춥니다.
셋째, 컨텍스트에 남은 비밀번호·키가 외부 로그로 흘러갑니다.
