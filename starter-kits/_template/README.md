# Starter Kit Template

이 템플릿은 runnable agent 예제를 추가할 때 사용한다.

## 목적

이 starter kit이 해결하는 가장 작은 업무 문제를 적는다.

## 대상 사용자

- PM
- 운영자
- 교육생
- 1인 빌더

## Public-first safety

이 예제는 공개/합성 데이터만 사용한다. 실제 고객 정보, API key, private URL,
계약/약관/사번/전화번호/계좌/결제 정보는 사용하지 않는다.
