# Case Study Template

이 템플릿은 외부 레퍼런스나 fork 콘텐츠를 AI_Engineer 관점으로 재정의할 때 사용한다.

## 왜 골랐나

- 원본이 어떤 문제를 잘 보여주는지 적는다.
- 이 레포의 독자에게 왜 필요한지 적는다.

## 원본이 잘하는 것

- 구조
- 설명
- 코드
- 운영 패턴
- 검증 방식
