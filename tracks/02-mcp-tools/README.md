# Track 02 — MCP Tools

Agent가 실제 업무 도구를 읽고 쓰게 만드는 연결 계층을 다룬다.

## 핵심 질문

- 어떤 업무는 chat 입력이 아니라 tool 연결이 필요한가?
- 연결 전에 어떤 데이터 경계와 권한을 정해야 하는가?
- MCP를 비개발자에게 어떻게 설명하고 실습시킬 것인가?

## 우선 case study

- `mcp-for-beginners`
- `real-estate-mcp`
- 공개 API 기반 단일 도구 예제

## 완료 기준

- 도구 연결 전후의 차이를 설명한다.
- public dummy data로만 실습한다.
- 실패 시 fallback path를 기록한다.
