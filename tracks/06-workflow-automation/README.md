# Track 06 — Workflow Automation

반복 업무를 prompt, skill, command, automation으로 전환하는 방법을 다룬다.

## 핵심 질문

- 한 번 쓰는 prompt와 재사용 가능한 skill의 경계는 어디인가?
- 업무 자동화가 사람 승인선을 넘지 않게 하려면 무엇을 적어야 하는가?
- 마케팅, 리서치, 문서 업무를 어떻게 검증 가능한 루프로 바꾸는가?

## 우선 case study

- `geo-seo-claude`
- `ai-marketing-skills`
- `ai-prompts-playbook`

## 완료 기준

- 반복 업무 하나가 입력, 처리, 출력, 검증으로 분해된다.
- 사람 승인선과 실패 처리 방식이 문서화된다.
