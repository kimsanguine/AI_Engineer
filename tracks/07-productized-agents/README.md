# Track 07 — Productized Agents

Agent 데모를 실제 제품 또는 운영 루틴으로 바꾸는 판단을 다룬다.

## 핵심 질문

- 이 Agent는 누구의 어떤 반복 문제를 해결하는가?
- model cost, latency, reliability는 제품화에 견딜 수 있는가?
- build, buy, hold 중 무엇이 맞는가?

## 우선 case study

- `vibe-investing`
- `kronos`
- finance/data agent 예제
- hplan build gate와 연결

## 완료 기준

- 제품화 판단 문서가 있다.
- 운영 지표와 중단 기준이 있다.
- public demo와 production claim을 분리한다.
